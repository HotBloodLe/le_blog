# 投稿方法

- 打开这个博客的Gtihub仓库的issues，链接[在此](https://github.com/HotBloodLe/le_blog)；

- 新建一个issues，正常输入标题，在文章最前面两行写上：

`本文作者：（你的名字）`
`使用标签：（标签名字，若没有写无）`

- 值得一提的是，可以在[这里](https://github.com/HotBloodLe/le_blog/labels)查看现有标签，也可以提供没有的名字创建一个新标签，像正常的Github issues一样写文章，最后创建。

- 审核通过后，我会加上"非官方发布"标签和其他你要求的标签，稍作等待就可以在[乐博客](https://hotbloodle.github.io/le_blog/)看到自己的文章了。

# 投稿规则

- 任何违反中华人民共和国法律法规的内容。

- 冒充其他人发表的内容。

- 含有引战/挑衅/诋毁/辱骂/谣言/地图炮/人身攻击/政治敏感/暴力邪教等破坏社区氛围的内容。

- 含有刷屏/恶意大图占屏/色情/广告/服务器宣传/推广链接等影响正常浏览的内容。

- 含有无授权/商用/非法的资源下载链接或引诱下载这些非法资源的内容。

- 含有不被编辑器允许的html代码。

- 无内容或**过于**毫无意义的文章，例如纯数字/字母毫无规律的组合等无表达信息的内容。

- 纯抢楼的文章，例如“沙发”、“抢板凳”等纯抢楼，不包含其他信息的内容。

（规则使用[[#2] 主站短评常见问题与守则](https://bbs.mcmod.cn/thread-609-1-1.html)作为参考）
